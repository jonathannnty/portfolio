Which elements should get the brushstroke treatment?

Green = brushstroke border · Gray = stays solid. Shown as a layout map of the projects page.

A — Selective

Only cards, chips, and buttons get the treatment. Nav border, image frames, blockquotes, and contact form stay solid.

B — All UI Elements (Recommended)

Everything interactive + image frames get the treatment. Nav/footer structure lines stay solid so the page skeleton stays clean.

C — Truly Everything

Every CSS border site-wide, including the nav bottom line and footer divider. Maximum handdrawn feel, but structural lines may look jittery.
